# Qatar-Hotel-Performance-and-Revenue-Analysis
Project Overview

This project analyses Qatar's hotel and accommodation performance using Excel and Power BI. It focuses on revenue trends, occupancy rates, hotel segments, and seasonal performance.

Objectives

Analyse hotel revenue and occupancy trends.

Identify top-performing hotel categories.

Understand seasonal patterns.

Generate business insights and recommendations.

Tools Used

Microsoft Excel – Data cleaning and preparation

Power BI – Data visualization and interactive dashboards

Key Insights

Compare revenue performance across hotel categories.

Identify the highest-revenue year and month.

Analyse occupancy patterns.

Highlight opportunities to improve hotel revenue.

Outcome

An interactive Power BI dashboard providing meaningful insights to support data-driven decision-making in Qatar's hospitality industry.
